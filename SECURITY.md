# Security Policy

## Supported Versions

Critical security updates and dependency patches are maintained for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |
| < 1.0   | No                 |

## Reporting a Vulnerability

We prioritize the security and integrity of this software. If you discover a security vulnerability or potential risk, please adhere to responsible disclosure practices:

1. **Do not create public GitHub issues** for security vulnerabilities.
2. Report the vulnerability privately via email to: **shahahmar882@gmail.com**
3. Include detailed reproduction steps, target component details, and potential impact assessment.

### Response Commitment
- **Initial Acknowledgment:** Within 48 hours of receipt.
- **Triage & Assessment:** Within 5 business days.
- **Remediation & Patch Release:** Scheduled according to CVSS severity scoring.
